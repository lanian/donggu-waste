# 동구 대형폐기물 접수·수거 관리 시제품

전화 접수부터 수거·마감·세입 확인까지 한 흐름으로 처리합니다.

```
PC: 전화 접수 → 행정동·위치 지정 → 노선 계산·배정 → 암호화 분할 QR 표시
휴대폰: QR 수신 → 길안내·도착·연락·스티커 확인·품목·수수료·금액 고지·사진·수거 결과 (오프라인)
휴대폰 → PC: 암호화 결과 파일(업무 메일) · 암호화 사진 파일(보안 매체)
PC: 결과 병합·충돌 검토·사진 회수 → 일일 마감(담당자 기록 → 팀장 확인) → 수납·세입 대사·환불 결재
```

> **시제품입니다. 가상 자료로 시험하세요.** 실제 주민 정보로 쓰기 전에 아래 "운영 전 확인·기관 결정 필요"를 마쳐야 합니다.

현재 버전: **PC v0.12 · 휴대폰 앱 0.12.13**


## 구성

| 부분 | 내용 | 실행 |
| --- | --- | --- |
| **휴대폰 앱** (`web/`) | Android·아이폰 공통 PWA. 업무 자료는 휴대폰 안에만 암호화 저장(서버에 두지 않음) | https://lanian.github.io/donggu-waste/ → 홈 화면에 추가 |
| **PC 프로그램** (`pc/`) | 접수·행정동·배정·노선·QR 전송·결과 병합·마감·수납·세입·환불·통계·개인정보 관리. 기본은 이 PC(127.0.0.1)에서만 열림 | `python pc/pc_tool.py serve` |
| **수수료표** (`data/`) | 공식 [별표 1] 원문 HWP와 변환본 169행 | `tools/convert_fee_hwp.py` |

휴대폰 앱은 처음 실행할 때 **PC와 연결해서 사용(권장)** 또는 **이 휴대폰만으로 사용** 중 하나를 고릅니다.

색 규칙(휴대폰·PC 같음): 녹색 = 완료, 노랑 = 사람이 봐야 함(확인 필요·재방문), 빨강 = 막힘·거부, 파랑 = 정보(처리 중·현장 추가), 회색 = 중립(취소 포함). 같은 일은 같은 말(금액 확인 대기, 수거 완료, 보류, 하차 기록, ← 목록). 확인창은 브라우저 창이 아니라 화면 안 대화상자입니다.

## PC 프로그램 설치·실행

```bash
pip install -r pc/requirements.txt   # 버전·해시 고정본
python pc/pc_tool.py init            # 암호화 DB와 PC 키 생성 (처음 한 번)
python pc/pc_tool.py serve           # 브라우저에서 http://127.0.0.1:8765
```

처음 열면 **운영 관리자 계정**(아이디 + 10자 이상 비밀번호)을 만듭니다. 업데이트·백그라운드 실행(서비스)·로그 위치는 [docs/배포·운영.md](docs/배포·운영.md)를 보세요.

### 역할

| 역할 | 할 수 있는 일 |
| --- | --- |
| 운영 관리자 | 전체 + 설정(행정동·한도·휴무일·감면·백업·개인정보)·휴대폰 등록·사용자·변경 이력·접속기록·백업·파기 |
| 팀장(검토자) | 모든 업무 조회(변경 이력·접속기록 포함), **마감 확인**(기록한 사람과 달라야 함), **환불 결재**(신청자와 달라야 함), **월 접속기록 점검**, **월보** 출력. 접수 수정·설정·사용자 관리는 못 함 |
| 접수 담당자 | 접수·배정·목록 전송·결과·충돌·수납·마감 기록·세입 대사·환불 신청·지급 기록·통계, 수수료표 개정안 승인(작성은 관리자) |
| 수거팀 | 조회, 결과·사진 가져오기, 하차 기록, QR 실측. 연결한 팀의 배정만 보임 |

사용자는 **사용자·이력** 화면에서 임시 비밀번호로 추가하며, 첫 로그인 때 비밀번호를 바꿉니다. 계정은 지우지 않고 중지합니다. 서버가 역할별로 API를 막고(403), 모든 변경 이력에 작업자가 남습니다. 로그인 실패 잠금은 계정마다 따로(5번째부터 30초, 늘어나며 최대 30분).

### 기능

**접수**

1. **전화 접수**: 양식은 전화 순서대로(신청자 → 물건 → 일정 → 위치), 접수 경로(전화·방문·온라인·단체(공동주택)·기타), 접수 시 안내 문구 표시. 같은 연락처·주소는 중복 후보 경고(자동 병합 없음). 수정은 사유 필수·버전 보존, 취소는 **사유 코드**(관할 밖·주민 취소·중복 접수·품목 불가·기타)와 함께
2. **주소 검색**: 이 PC의 주소 위치 자료에서 도로명·**지번·건물명·초성**으로 찾고 위치·행정동 자동 채움. 못 찾으면 지도를 눌러 지정
      **행안부 도로명주소 API**(설정 → 주소·외부 서비스에 승인키): PC 서버가 대신 검색·좌표 조회(브라우저에는 키가 가지 않음, 저장 후 끝 4자리만 표시). 이 PC 자료 결과가 먼저, 행안부 결과는 "행안부" 표시. 검색어에 연락처 형태·8자리 이상 숫자·입력 중인 이름·저장된 주민 이름이 있으면 보내지 않음. 접속기록에는 건수만, 서버 로그에는 검색어 없음
3. **행정동 관리**(설정 → 행정동): 아래 별도 설명
4. **수거 한도·휴무일 달력**: 접수 화면에 다음 업무일 14일의 예약/한도(전체·동별 건수·m³), **[가장 빠른 가능일]**, 한도 초과·휴무일·수거 요일 아님 경고(막지는 않음). 설정 → 한도·휴무일
5. **일괄 처리**(접수 목록에서 여러 건 선택): 예정일 변경·취소(사유 코드)·동 지정·목록 인쇄·배출 표지·CSV. 건별 이력이 남음
6. **CSV 접수 가져오기**: 서식 CSV 내려받기 → 미리보기(오류·경고·중복 후보) → 오류 행은 빼고 한 번에 등록(중복 후보도 뺄 수 있음)
7. **민원·통화 기록**(접수 상세): 문의·독촉·변경요청·불만을 접수에 연결해 기록
8. **감면**: 접수마다 감면 사유·감면율·증빙 확인 방법(서류 확인·행정정보 공동이용 등)·확인자. 계산 금액 → 감면액(원 미만 버림) → **부과 금액**. 주민등록번호·수급자 증명번호는 저장하지 않음. 사유 목록(기본 예시는 "조례 확인 필요")은 설정 → 수수료·감면
9. **부과번호**: 접수할 때 `연도-동코드-일련번호` 자동 부여(동 코드 비면 `00`)
10. **유사 품목 적용**(접수 상세 → 현장 결과): 표에 없어 확인 대기인 품목을 단가가 확정되고 부과단위가 같은 행에 연결(근거·확인자, 해제도 사유와 함께)
11. **관할 확인**: 주소의 구 이름이 관할(기본 동구)과 다르면 경고(막지는 않음)
12. 접수 목록: 입력하는 대로 찾기(초성 `ㅈㄹ` → 장롱), 빠른 거르기(오늘 예정·위치 없음·금액 확인 대기·미배정), 동 거르기, 쪽 넘김. 단축키 `/` 찾기 · `N` 새 접수 · `Ctrl+Enter` 저장

**배차·수거**

13. **배정·노선**: 날짜·팀 선택 → [노선 계산](OR-Tools). 방문 약속 시간, 오늘 필수, 우선순위, 적재 추정치, 근무시간, **동 기본 담당 팀 우선**(약한 선호) 반영. 25m 안의 접수는 같은 장소로 묶어 연속 방문(접수·수수료·완료는 건별). 미배정 건은 사유 표시, **다른 날로 미루기**(사유 코드). 순서·팀을 손으로 바꾸면 조정 사유 필수
14. **반입지·종료지**(설정): 적재가 차면 반입지에 들러 비우는 순서 추천, 확정한 경유 위치와 **반입지 좌표**를 휴대폰 목록에도 전달(휴대폰 반입지 길안내)
        **이동시간 계산 방식**(설정 → 주소·외부 서비스): 직선거리 추정(기본) / 로컬 OSRM / **카카오모빌리티 API**(REST 키). 카카오는 좌표만 보내고 결과를 30일 보관(재사용), 받지 못한 구간만 직선 추정으로 채워 화면에 "도로 시간: 카카오모빌리티 (일부 직선 추정 N쌍)"처럼 표시. 배정 화면의 지점마다 **카카오맵** 링크(좌표와 "N번 수거지"만)
15. **목록 전송**: [QR 표시] → 휴대폰 [오늘 목록 받기] → 휴대폰의 수신 확인 코드 입력. 배차표 인쇄(팀별 순서·동 열·체크 칸, 파쇄 안내·출력 기록)
16. **결과 가져오기**: 결과 파일(.dgr)·사진 파일(.dgp) → 보관 종료·사진 회수 확인 코드 발급. 휴대폰 새 기록(도착·스티커 확인·금액 고지·증거 사진·작업자)을 접수 상세에 표시. 오래된 배정·취소 건 결과는 **충돌함**에서 반영/거부. 메일이 막히면 결과 QR을 PC 웹캠으로 읽기. 휴대폰 단독 방식 백업(.dgb) 옮기기
17. **QR 실측**·**적재량 보정**(설정)

**정산·마감**

18. **일일 마감 2단계**: 담당자가 결과 미회수·재방문 후보·금액 확인 대기·수납 확인 필요·사진 미회수·충돌·스티커 문제·금액 고지 거부·증거 없는 미수거를 확인하고 [마감 기록] → 끝나지 않은 건은 **다음 업무일로 실제 이월** → **팀장이 확인**. 다시 마감하면 새 **회차**로 쌓이고 다시 확인 필요. 마감 뒤 수정은 사유 필수. 팀장 확인 때 보유기간 지난 개인정보 파기와 자동 백업이 이어서 실행
19. **수납 기록**(접수 상세): 결제 방법·영수번호와 함께 담당자가 확인한 납부·환불 기록. 부과 금액과 비교해 미납·부족·과납 표시. 정정은 지우지 않고 사유 기록
20. **세입·대사**: 세입 일계·월계(결제 방법·동별), CSV. 세외수입 납부 자료 CSV를 양식대로 넣으면 부과번호로 맞춰 미리보기(일치·금액 다름·부과번호 없음·중복 등) → 일치 행만 납부(출처 '대사')로 기록, 같은 파일은 한 번만
21. **환불 결재**: 납부 뒤 취소·과납은 환불 건 자동 생성 → 담당자 신청 → **팀장 결재**(신청자 아닌 사람) → 지급 기록(지급일·방법, 계좌번호는 저장 않고 "계좌 확인함"과 끝 4자리만)
22. **출력**: **접수증**(신청인 보관용, 접수·부과번호·계산→감면→부과 금액·문의처), **배출 표지**(A4 한 장에 6개, 접수번호만 담은 QR), **월보**(개인정보 없음, 제목은 설정). 모든 출력은 접속기록에 남음
23. **통계·보고서**: 집계 기준 선택(수거 예정일·접수일·완료일), 기간별 접수·완료율·재방문·금액, 동별·품목 분류별·세입·감면·접수 경로·월별 집계, 이름·연락처·주소 없는 접수별·날짜별 CSV
    **시범 운영 비교**(v0.12): 기간·팀과 기존 방식 수치를 넣으면 이 시스템 기록으로 누락·재방문·독촉·불만(100건당), 평균 처리 일수, 접수 1건·하루 마감 시간(PC 화면에서 자동 측정), 당일 결과 회수, 금액 확인 대기를 계산해 나란히 비교(좋아짐/나빠짐), CSV

**관리**

설정 → **행정동**에서 동마다 다음을 정합니다. 바꾼 내용은 변경 이력에 남습니다.

## 휴대폰 앱 사용

- **PC 연결 방식**: 기기 등록 → 오늘 목록 받기(다시 받으면 새로·변경·빠짐 표시) → 상세 → 품목·수량·수수료 → 사진 → 수거 결과 → 결과 보내기(업무 메일) → 사진 파일 만들기(보안 매체) → 각 확인 코드 입력
  - **단독 방식에 있던 일도 PC 연결 방식에서 (v0.12)** — PC가 원본이므로 휴대폰은 바로 고치지 않고 *요청*으로 보내고 사무실이 확인합니다
    - **[+ 접수 등록 (현장·전화)]**(홈 위, 기기 등록 전에도 가능 — 보내기만 등록 뒤): 수거 중 새로 요청받거나 전화로 받은 건을 접수, 경로 현장(기본)·전화·방문 → 임시번호(현장-MMDD-N 등)로 목록에 들어가 현장 접수는 바로 처리 가능 → 결과 보내기 때 PC 원본 접수가 됨(고른 경로로). 금액은 PC 수수료표로 다시 계산, 표에 없는 품목은 확인 대기. PC [현장 접수 확인]에서 담당자가 확인
    - **보내기 전 고치기**(0.12.12): 이 휴대폰에서 받은 접수를 아직 결과 파일로 내보내지 않았으면 지점 화면 [접수 고치기 (보내기 전)]로 바로 고침(보낸 뒤에는 정정 요청)
    - **[정정 요청]**: 이름·연락처·주소·상세 위치·예정일. PC 충돌함([현장 요청] 탭)에 "지금 값 → 요청 값"으로 나오고 [반영]하면 원본을 고침(이전 내용은 버전 이력, 주소가 바뀌면 위치는 다시 지정, 날짜가 바뀌면 배정 해제). 요청한 새 연락처로 휴대폰에서 [새 번호로 전화]
    - **[취소 요청]**: 사유 코드(주민 취소·중복·품목 불가·관할 밖·기타). PC가 확인한 뒤 취소(납부가 있으면 환불 필요로)
    - **방문 순서 바꾸기**: 이 휴대폰에서만 순서를 바꿔 다님(PC 노선·배정은 그대로, 새 목록을 받으면 PC 순서로). [PC 순서로 되돌리기]
    - 단독 방식의 **휴대폰 단가 확정**은 PC 연결 방식에 넣지 않음 — 단가는 PC 수수료표 개정(2인 승인)이 기준
- **현장 점검**(설정 → 현장 점검, 0.12.13): 자동 시험으로 확인할 수 없는 것(설치·지문·주소 검색·카카오맵/T맵/네이버 길안내·카메라 다녀오기·QR·전화/문자)을 이 휴대폰에서 [시험]으로 눌러 보고 된다/안 된다/메모를 남김. 카메라 시험 중 앱이 다시 열리면 자동으로 '안 된다'. [결과 복사]로 기기·브라우저·앱 버전과 결과를 담당자에게(주민 정보 없음)
- **설치**: 브라우저 탭에서도 그대로 동작해 설치 전에도 앱처럼 보임 → 설정에 **실행 위치**(브라우저 탭/설치한 앱)와 설치 단추·안내(0.12.2). 아이폰은 Safari와 홈 화면 앱의 자료가 따로라 설치한 앱에서 시작
- **배출 주소 확인·동 정하기**(0.12.11, 휴대폰 안 자료로만 — 주소를 밖으로 보내지 않음): 건물번호(번지) 없음, 도로명·지번 형식 아님, 관할(구) 밖·다른 시도, 주소칸의 전화번호를 알림(막지 않음 — 저장 때 한 번 보여 주고 다시 누르면 저장). 동은 주소의 행정동 이름 → 같은 도로·법정동의 이전 접수 → 법정동 줄기 후보(예: 계림동 → 계림1·2동) 순으로 추천·자동 채움, 동구 행정동 목록에 없는 이름은 오타 알림. PC 접수 화면도 주소를 바꾸면 같은 확인을 보여 줌
- **품목 담기**(전화 접수·현장 접수, 지점의 [+ 현장 품목 추가]도 같은 화면 — 0.12.6): [+ 품목 담기] → 전용 화면. **글자 없이 눌러서**: 분류 탭(자주 쓴·가전·가구·생활·기타·담음) → 품목 이름 단추 → 규격이 여럿이면 규격 고르기 창(규격마다 [+ 담기]/[− N +]), 하나면 바로 담김. 이름 검색(초성)도 가능 — 담기를 눌러도 키보드가 유지되고 검색어가 선택돼 바로 다음 품목 입력. 아래에 담은 요약과 [완료] 고정, [담음] 탭에서 수량 조정·빼기, 목록에 없는 품목은 확인 대기로
- **단독 방식**: 전화 접수 등록 → 날짜별 목록·방문 순서 → 현장 처리 → 매일 암호화 백업(24시간 지나면 경고) → 나중에 PC로 옮기기
- **현장 처리**
  - **📍 도착**: 시각과(허용 시) 휴대폰 위치·정확도 기록. 위치는 결과 파일로만 PC에 감
  - 📞 전화 → 연락 결과(통화 완료 ≠ 수거 완료), 통화로 약속한 재방문 날짜·시간
  - **✉ 문자**: 문구(설정에서 편집)를 골라 문자 앱을 엶. 이 주민의 접수번호·시각만 들어가고, 기록엔 문구 종류만 남음
  - **스티커·신고필증 확인**(품목별 확인/없음/번호 불일치). 문제가 있으면 그 품목을 수거할지 바로 정함
  - **현장 금액 고지**: 접수 때보다 금액이 늘면 주민 안내 결과(동의·거부) 기록. 거부하면 늘어난 품목은 미수거
  - **사진 필수**: 부재·배출 안 됨으로 미수거하려면 사진 1장 이상 또는 찍지 못한 이유. 사진은 촬영 시각·위치와 함께 앱 안에만 암호화 저장(갤러리에 안 남음), 특정 품목에 묶기 가능

  - 반입지에서 **[하차 기록]**(시각·부피·중량)
- **작업자**: 설정에 이름을 넣어 두면 교대 때 PIN 없이 골라 바꾸고, 모든 기록에 작업자 이름이 남음

| PC 저장 | SQLCipher로 DB 파일 전체 암호화. DB 키는 운영체제 키 저장소(또는 시작 시 입력). PC 개인키도 DB 안에 보관. `sqlcipher3`가 없으면 평문으로 실행하지 않고 멈춤 |
| PC 화면 | 기본 127.0.0.1에만 열림, Host 검사, 사용자별 계정(scrypt)·역할별 API 제한, 세션 쿠키(HttpOnly·SameSite=Strict, 30분 무조작 만료), CSRF 헤더 필수, 계정별 로그인 잠금 |
| LAN 모드 | 기본 꺼짐. 켜면 HTTPS 전용(TLS 1.2 이상)·Secure 쿠키, 허용 IP 대역 밖 연결은 끊음, 모든 주소 허용 거부, Host는 서버 이름만. 정보화부서 승인 필요 |
| 서버 로그 | `server.log`: 방법·**경로 틀**(ID처럼 보이는 부분은 `:id`로 가림)·상태 코드·걸린 시간·사용자 아이디·접속 위치. 주소 뒤 조건(query)·본문은 남기지 않음. 오류 내용은 전화번호·도로명 주소 모양을 가려서 기록 |
| 접속기록 | 개인정보를 연 기록(누가·언제·무엇을·건수·조건)을 암호화 DB에 남김. 2년 이상 보관, 팀장·관리자 월 점검 |
| 해시 체인 | 접속기록과 변경 이력은 행마다 앞 행의 해시를 이어 받음 → 무결성 검사로 수정·삭제 발견(v0.11 이전 이력은 '이전 기록'으로 검사에서 뺌) |
| 파기 | 보유기간 지난 접수는 사람을 알아볼 수 있는 값만 지우고(가명 처리) 파기 대장에 기록. **이전 백업 파일에는 남아 있으므로** 백업 보관 기간에 따라 지움 |
| 휴대폰 저장 | IndexedDB 레코드별 AES-GCM, 데이터 키는 PIN(PBKDF2 60만 회)으로 감쌈(지문·얼굴은 PRF로 추가 감쌈), 자동 잠금, 사진은 갤러리에 남지 않음 |
| 전송 | 묶음마다 새 ECDH P-256 키 → HKDF → AES-256-GCM, ECDSA 서명. 복호화 키는 QR에 없음. 조각 누락·중복·혼합·변조·다른 기기·오래된 버전 거부 |
| 결과 파일 | 이름·연락처·주소·메모 없음, PC만 열 수 있음. 같은 기록은 한 번만 반영. **예외(v0.12)**: 현장 접수·정정 요청이 있으면 PC가 원본을 만들거나 고치는 데 필요한 그 건의 이름·연락처·주소가 들어감(휴대폰이 보내기 전에 알림, 같은 PC 전용 암호화). PC는 처리한 요청 기록에서 이 값을 지우고(원본은 접수·버전 이력에만), 휴대폰도 반영 확인 뒤 지움 |
| 사진 | 결과 파일과 분리, 암호화 사진 파일로 보안 매체 회수, PC가 해시 대조 후에만 회수 확인 코드 발급 → 그 뒤에만 휴대폰에서 삭제 가능 |
| 외부 통신 | ① 바탕 지도 조각(`tiles.openfreemap.org`, 줌 14 이하 넓은 범위)만 — PC·휴대폰. ② 휴대폰 주소 검색: 행정안전부 도로명주소 API(`business.juso.go.kr`)로 **검색어와 승인키, 고른 건물 식별 번호만**. ③ 길안내: 휴대폰의 지도 앱에 **좌표와 "N번 수거지"만**. ④ PC 서버(승인키·REST 키를 넣었을 때만): 행안부 도로명주소 API로 검색어·건물 식별 번호, 카카오모빌리티로 **좌표만**. PC 화면(브라우저) 자체는 지도 조각 서버만 연결. **이름·연락처는 어디로도 나가지 않음.** 쿠키·Referer 안 보냄, CSP로 허용 서버만 연결 |
| 백업 | 수동: DB 키와 다른 백업 비밀번호로 암호화. 자동: 백업 공개키(X25519)로 암호화, 개인키는 PC에 없음. 복원 시 현재 DB 키로 다시 암호화하고 기존 DB는 지우지 않음 |
| 변경 이력 | 작업자·시각·대상·작업. 내용에는 사유·건수·코드만(이름·연락처·주소 없음). 화면에서 고치거나 지울 수 없음 |
| 감면·환불 | 주민등록번호·수급자 증명번호·계좌번호 저장 안 함(계좌는 확인 여부와 끝 4자리만) |
| 분실 기기 | PC에서 "분실 처리" → 그 기기로 목록 전송 불가, 결과 거부. 오프라인 기기의 원격 삭제는 약속하지 않음 |

## 알려진 제한

- 노선 이동시간은 로컬 OSRM이 없으면 **직선거리 추정**(화면에 표시). 실시간 교통·음성 길안내·현장 재최적화는 없음(길안내는 외부 지도 앱에 맡김)
- 휴대폰 주소 검색: 행정안전부 서버가 브라우저 요청(CORS)을 허용하는지 **실제 휴대폰에서 아직 확인 안 됨**. 막히면 검색이 실패하고 직접 입력·지도 지정으로 넘어감(PC 방식은 PC에서 주소 작업)
- 길안내 앱 주소(카카오맵·T맵·네이버지도 URL 스킴)는 **실제 기기에서 아직 확인 안 됨**. 앱이 없을 때 웹으로 넘어가는 동작도 기기마다 다를 수 있음
- Android에서 카메라 앱을 오가는 동안 브라우저가 앱을 다시 불러오면 방금 찍은 사진이 사라질 수 있음(다시 찍어야 함)
- 자동 백업 중 DB 잠금은 암호화 내보내기 동안만 잡음(파일 봉인·복사는 잠금 밖). 자료가 아주 크면 내보내는 몇 초 동안 PC 화면이 기다릴 수 있음
- Windows·macOS의 PC 로직 시험은 CI에서 참고용(경고만). 화면 시험은 Linux Chromium에서만
- 주소 위치는 건물 출입구 좌표(위치정보요약DB 기준). 처음 가져올 때 미리보기로 표본 위치 확인
- 적재 부피는 품목별 추정치에 담당자 보정값을 더한 것
- 휴대폰 단독 방식의 단가 확정은 그 휴대폰에만 적용(PC 개정·2인 승인과 별개)
- 수납은 담당자 확인 기록과 대사 CSV 반영이며 온라인 결제·세외수입 자동 연계는 없음. 계산 금액은 수납 완료를 뜻하지 않음
- 웹 앱의 키는 하드웨어 보안 영역에 묶이지 않음(지문·얼굴은 PRF 지원 기기만). 브라우저 데이터 삭제 시 휴대폰 미전송 기록 소실
- 파기는 이후 백업 파일까지 지우지 않음(백업 보관 기간으로 관리)
