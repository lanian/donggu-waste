# PC 실행 앱 운영·LAN 점검 검증

검증일: 2026-11-15. 브랜치: `feat/desktop-operations-20261115`. 기준 소스 `5fe6a12`, 설계 `3060e4e`. 앱 버전은 0.14.21을 유지한 **별도 preview**이며 공개 배포·기존 설치 교체는 하지 않았다.

## 변경 사항

- 로컬 기본값을 유지하고 같은 기관망 HTTPS 프로필 설정·검증·정상 재실행을 제공한다. 명시적 실행 인자가 저장 설정보다 우선하며 자료 위치·알 수 없는 설정 필드를 보존한다.
- 접속 주소 복사, 별도 연결 시험, 실제 디스크 여유 공간·선택 폴더 접근 표시, 로그 폴더 열기, 안전한 JSON 보고서를 추가했다.
- 점검 전용 GUI와 `--check-connection URL --check-output JSON`은 자료·프로필·DB 키·서버·mutex 초기화 전에 분기한다. 검사한 기기의 범위를 표시하며 다른 기기 도달성을 대신 확정하지 않는다.
- HTTPS는 정상 신뢰·이름 검증과 TLS 1.2 이상을 사용한다. 만료·SAN·키쌍과 허용 CIDR을 DB 키 요청 전에 검증한다. IPv4/IPv6 대역 조합이 `/0`이 되어도 거부한다.
- 로컬·LAN 상태 조회 모두 전체 시간 12초, API 64KiB, HTML/자산 1MiB, 진입 script 16개 상한을 사용한다. 외부 출처·redirect·개인정보가 붙은 URL을 거부한다.
- 진단의 Controller/epoch 소유권과 저장 대화창 반환 후 검사를 적용했다. 예기치 않은 서버 종료·연결 상실·폴더 변경 뒤 옛 결과가 남지 않도록 했다.

## 검증용 산출물

- 폴더: `dist/desktop/preview-ops-20261115/Donggu-PC/`
- EXE: 8,993,769 bytes, SHA256 `67d665232f29790e31ecf41446b33879ffa9970b177f453dd45f4d073b3178b4`
- ZIP: 66,858,877 bytes, SHA256 `b1bb56f2d91ac78cecb60b657ce03382e148abe9036959f449f4ceaf10f05979`
- 포함 도구: `PC 접속 점검.cmd`, `접속점검안내.txt`. `_internal/`을 포함한 폴더 전체가 필요하다.
- 로컬 시험 로그: `D:/Temp/dg-desktop-operations-20261115/integration/`; 독립 검토와 각 담당자의 RED/GREEN 증거도 임시 폴더에 보관했다. 업무 자료는 포함하지 않는다.

## 보존과 검증 범위

기존 0.14.21 EXE/ZIP, 외부 `AGENTS.md`의 SHA256은 작업 전과 같다. 기존 바로가기는 0.14.21 대상·`--port 8766`·기존 작업 폴더를 유지한다. 운영 DB·방화벽·공유기·인증서 신뢰 저장소를 변경하지 않았다. 공개 사이트와 모바일 자산도 변경하지 않았다.

실제 다른 물리 PC의 기관망 연결, 기관 인증서·DNS·방화벽 적용, 운영 계정 로그인·실자료 처리, 실제 배포 EXE 창의 수동 시각 조작과 OS 배율 변경 시험은 이번 증거에 포함되지 않는다. 기관 설정 후 다른 PC에서 점검기를 실행해야 실제 도달성을 확인할 수 있다. 사용 절차는 [운영·접속 점검 안내](../PC-실행앱-운영점검.md)를 따른다.
