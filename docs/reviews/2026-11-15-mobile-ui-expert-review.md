# 휴대폰 화면 전문가 검토와 개선안 (0.14.25)

검토일: 2026-11-15 · 대상: `web/` 0.14.25 (`1df1f54`) · 파일 수정 없음(분석만)

## 검토 방법

- **화면 캡처:** 가상 자료로 실제 PIN·암호화 저장소를 쓰는 앱을 띄워 52장을 찍었다. 기본·다크·아주 큰 글씨·짧은 화면(360×640)·단독 방식이다. 시나리오는 6곳 수거 목록(완료·일부·부재·미수거·방문 전)과 보내지 않은 기록 7건이다.
- **전문가 4명:** 같은 캡처와 코드를 독립적으로 봤다.
  - 현장 동선
  - 정보 구조·문구
  - 접근성·야외 가독성
  - 시각 디자인 시스템
- **제외 범위:** 11-14 현장 검토와 11-14·15 모바일 개편에서 이미 고친 항목은 뺐다.
- **통합 검증:** 두 명 이상이 겹쳐 낸 항목과 P1 항목은 통합 검토자가 코드를 직접 대조했다(아래 ✔).
- **캡처 정정:** 처음 찍은 아주 큰 글씨 캡처에는 글자 크기가 적용되지 않았다. 다시 찍었다. 접근성 검토자는 CSS 측정 틀로 직접 재서 360px에서 가로 넘침이 없음을 확인했다.
- **검토 한계:** 실제 휴대폰·TalkBack·현장 작업자 시험은 포함하지 않았다.

## 한눈에 보기

가장 큰 문제는 세 가지다.

1. **저장하지 않은 결과가 저장된 것처럼 보인다.** 수량 입력만으로 "일부 수거"가 표시된다.
2. **다음 행동이 하나로 보이지 않는다.** 홈에 초록 큰 단추가 둘이고, 노란 상자가 안내·성공·경고에 모두 쓰인다.
3. **예외 처리(부재·미수거)가 길다.** 사유를 고르고 증거 사진을 찍느라 같은 화면을 위아래로 여러 번 오간다.

## 유지할 것 (네 명이 공통으로 꼽음)

- **"지금 할 일" 카드:** 상황에 맞는 다음 행동 하나를 고르는 구조다. 다른 주 행동만 낮추면 된다.
- **저장 상태에 따라 바뀌는 하단 바:** "결과 선택 ↓ → 저장 중 → 다시 시도 → 다음 N번". 저장 전에는 다음으로 넘어가지 않는다.
- **전화 뒤 복귀:** 전화를 걸고 돌아오면 연락 결과로 이동하고 강조한다.
- **노선도와 진행선:** 방문 순서 노선도(번호 원·세로선·"지금")와 처리 단계 진행선.
- **글자 크기와 누르는 곳:** 누르는 곳 56px 이상, `--fs` 한 값으로 바꾸는 글자 크기, 아주 큰 글씨에서 1열 배치(360px 넘침 없음).
- **대비와 색 규칙:** 다크·고대비의 글자 대비(6:1 이상), 색 규칙 주석과 상태별 `*-bg/*-ink` 토큰 짝.
- **개인정보 안내:** 넘기는 시점에 구체적 건수로 보여 주고, 길안내에는 좌표와 번호만 넘긴다.
