# 동별 관리

전체 업무와 담당 동 업무는 같은 **동별 관리** 화면을 사용합니다. 여러 PC가 같은 자료를 사용하려면 기관에서 준비한 PC 서버에 접속해야 합니다. PC마다 별도 자료 폴더로 서버를 시작하면 자료도 각각 분리됩니다. 접속 설정은 [배포·운영 안내](배포·운영.md)를 따릅니다.

## 계정과 담당 동 설정

1. 관리자가 **설정 → 행정동**에서 사용할 동을 등록합니다.
2. **사용자·이력**에서 역할을 **동 담당자(지정 동)**로 고르고 담당 동을 한 개 이상 선택해 계정을 추가합니다.
3. 담당자는 첫 로그인 때 임시 비밀번호를 바꿉니다. 이후 **동별 관리**가 기본 화면으로 열립니다.
4. 담당 동이 바뀌면 관리자가 사용자 목록의 담당 동을 변경합니다. 이름을 바꾼 동도 기존 연결은 유지됩니다.

운영 관리자·접수 담당자는 모든 동 또는 특정 동을 선택합니다. 동 담당자는 지정된 동 전체 또는 그중 한 동을 선택합니다. 팀장은 조회만 합니다. 담당 동이 없는 계정에는 전체 자료를 대신 보여주지 않습니다.

## 하루 업무 순서

1. **기준일·행정동 범위**를 선택합니다. 예정·완료·미배정·재방문은 선택일 기준이며, 지난 미처리·예정일 없음은 전체 기간의 할 일입니다.
2. 동별 표나 지표를 눌러 해당 접수를 확인합니다. 이름·접수번호 등으로 목록을 검색할 수 있습니다.
3. **접수 등록**에서 담당 동·신청자·주소·예정일·품목을 입력합니다. 닫은 양식의 초안은 원래 동에서 다시 열 수 있으며 계정이 바뀌면 초기화됩니다. 브라우저를 닫은 뒤의 보관 수단은 아닙니다.
4. 수거 위치를 확인합니다. **주소로 위치 찾기**는 PC에 설치된 주소 자료를 사용합니다. 자료가 없으면 위치를 직접 입력하거나 전체 업무 담당자에게 확인을 요청합니다. 위치가 없는 접수는 노선에 넣을 수 없습니다.
5. 팀을 선택해 **노선 계산**으로 미리 보고, **배정 확정**에서 반영합니다. 날짜·동·팀이 바뀌면 다시 계산합니다. 휴대폰 목록 전송은 전체 업무 담당자가 기존 전송 화면에서 처리합니다.

## 충돌과 자료 범위

다른 동의 접수가 섞인 기존 팀 배정은 이 화면에서 통째로 교체하지 않습니다. 전체 업무 담당자에게 조정을 요청하세요. 다른 사람이 접수나 배정을 바꾼 경우 최신 내용을 확인한 뒤 다시 작업합니다.

**집계 CSV**에는 현재 허용 범위의 동별 건수만 담으며 주민명·전화번호·주소는 포함하지 않습니다. 동 담당자에게는 전역 보고서·수납·출력·파일 전송 메뉴가 제공되지 않습니다. 담당 범위 밖의 상세 조회나 변경 요청도 서버가 거부합니다.

## 업데이트 확인

0.14.0의 DB 구조 버전은 **8**입니다. 업데이트 시 기존 계정·접수 등을 보존하며 구조 변경 전 암호화 사본을 만듭니다. 이전 프로그램으로 새 DB를 직접 열지 마세요. 가상 동·가상 주민 자료로 계정별 범위와 첫 로그인 흐름을 확인한 뒤 사용합니다.
