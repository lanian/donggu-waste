# 동별 관리

전체 업무와 담당 동 업무는 같은 **동별 관리** 화면을 사용합니다. 여러 PC가 같은 자료를 사용하려면 기관에서 준비한 PC 서버에 접속해야 합니다. PC마다 별도 자료 폴더로 서버를 시작하면 자료도 각각 분리됩니다. 접속 설정은 [배포·운영 안내](배포·운영.md)를 따릅니다.

## 계정과 담당 동 설정

1. 처음 실행하거나 0.14.2 이상으로 업데이트하면 동구 기본 행정동 13개 중 없는 동이 자동 등록됩니다. 관리자는 **설정 → 행정동**에서 사용할 동과 담당 팀·요일·한도·코드를 확인합니다. 기존 설정은 보존하며, 이후 직접 삭제한 동은 재시작 때 다시 추가하지 않습니다.
2. **사용자·이력**에서 역할을 **동 담당자(지정 동)**로 고르고 담당 동을 한 개 이상 선택해 계정을 추가합니다.
3. 담당자는 첫 로그인 때 임시 비밀번호를 바꿉니다. 이후 **동별 관리**가 기본 화면으로 열립니다.
4. 담당 동이 바뀌면 관리자가 사용자 목록의 담당 동을 변경합니다. 이름을 바꾼 동도 기존 연결은 유지됩니다.

운영 관리자·접수 담당자는 모든 동 또는 특정 동을 선택합니다. 동 담당자는 지정된 동 전체 또는 그중 한 동을 선택합니다. 팀장은 조회만 합니다. 담당 동이 없는 계정에는 전체 자료를 대신 보여주지 않습니다.

## 직제순 변경

관리자가 **설정 → 행정동**에서 ↑·↓로 동을 이동한 뒤 **순서 저장**을 누릅니다. 동별 관리·접수·사용자 담당 동 선택에도 같은 순서가 적용됩니다. 사용 중지한 동도 순서 편집에 포함합니다.

**순서 되돌리기**는 순서만 원래대로 돌립니다. 이동·저장 실패·되돌리기 중에도 다른 항목의 입력은 유지합니다. 순서가 변경된 상태에서는 먼저 순서를 저장하거나 되돌린 뒤 동의 추가·수정·삭제를 할 수 있습니다. 다른 창에서 목록이나 순서를 바꾼 경우 자동으로 덮어쓰지 않으므로, 입력 내용을 확인하고 목록을 다시 열어 주세요.

## 동별 차고지와 전담팀 (0.14.8)

1. 관리자가 **설정 → 행정동**에서 기본 담당팀을 지정하고 **차고지 설정**을 엽니다. 실제 차고지 이름·위도·경도를 입력하거나 기존 로컬 주소 검색·지도 선택을 사용합니다. 위치는 자동 추정해 저장하지 않습니다.
2. **행에 적용**은 입력을 보관하는 단계입니다. 해당 행의 **저장**을 눌러야 서버에 반영됩니다. 취소하면 기존 값을 유지합니다. 공통 차고지로 돌아가려면 창 안의 **공통 차고지 사용** → **행에 적용** → 행의 **저장** 순서로 처리합니다.
3. 동별 관리와 전체 배정·노선 모두 팀별 차고지에서 출발하고 복귀합니다. 기존 **종료지**를 따로 지정했다면 그곳으로 종료합니다. 노선 미리보기와 지도에 실제 계산에 사용한 출발지를 표시합니다.

차고지를 지정한 동은 기본 담당팀에 고정합니다. 담당팀이 선택되지 않았거나 사용 중지 상태면 미배정 사유로 알리며 다른 동 팀에 넘기지 않습니다. 일반 배정·부분 수정에서도 같은 기준을 검사합니다. 서로 다른 차고지를 한 팀에 동시에 지정할 수 없으며, 같은 위치는 공유할 수 있습니다. 차고지 미지정 동은 기존 공통 차고지와 약한 선호 팀 동작을 유지합니다.

노선 계산 뒤 차고지·담당팀·종료지가 바뀌면 예전 결과로 확정하지 않고 재계산을 안내합니다. DB 구조 11로 이전할 때 기존 동의 모든 값은 보존하고 개별 차고지는 미지정으로 추가합니다. 실제 위치는 담당자가 등록합니다.

## 행정복지센터 차고지 (0.14.13)

동마다 전담팀 1개가 있는 운영은 **설정 → 행정동**에서 해당 팀을 선택해 행의 **저장**을 누른 뒤 **행정복지센터 차고지 일괄 적용**으로 설정합니다. 사용 중이며 담당팀이 다른 동과 중복 연결되지 않은 동의 비어 있는 차고지만 채웁니다. 기존 차고지는 유지하고, 담당팀 미연결·사용 중지·중복 연결 동은 미적용 내역에 표시합니다. 팀을 새로 만들거나 차량 한도·요일·순서를 바꾸지 않습니다.

개별 설정은 **차고지 설정 → 행정복지센터 위치 채우기 → 행에 적용 → 저장** 순서입니다. 공식 센터 13곳의 주소·지도 표식과 출처·확인일을 제공하므로 차량 출입 위치가 다르면 좌표를 조정하세요. 동명동은 동계천로 172, 학동은 안내된 임시 위치를 사용합니다. 일괄 적용 전에 작성 중인 행과 순서를 먼저 저장하세요. 응답이나 목록 조회가 끊기면 편집을 잠그며, **적용 결과 다시 확인**으로 최신 설정을 확인한 뒤 재개합니다.

## 하루 업무 순서

**날짜와 무관하게 접수 찾기(0.14.10)**: 검색어를 입력하고 **전체 기간 조회**를 누르면 담당 동 안의 완료·취소·예정일 없는 접수까지 찾습니다. 접수번호 검색도 가능합니다. 이전날·오늘·다음날이나 기준일을 고르면 선택일 목록으로 돌아옵니다. 화면 위 집계와 노선 계산·배정은 **집계·배차 기준일**을 사용합니다. 전체 기간 목록을 열어도 그 날짜의 배차 범위는 유지됩니다.

**PC 직접 수거**: 기존 접수를 열고 **수거 처리**에서 실제 수거일과 이번 추가 수거 개수를 입력합니다. 담당 동 계정도 자신의 동 범위에서 처리할 수 있습니다. 이전 수거분은 자동 보존하고 남은 수량 안에서만 입력하며, 일부·미수거 사유를 남깁니다. 배출표가 부족해도 수거 결과는 저장하고 미배정 장수를 안내합니다. 접수 수정 초안은 유지되지만 품목 수정은 먼저 저장해야 합니다.

1. **기준일·행정동 범위**를 선택합니다. 예정·완료·미배정·재방문은 선택일 기준이며, 지난 미처리·예정일 없음은 전체 기간의 할 일입니다.
2. 동별 표나 지표를 눌러 해당 접수를 확인합니다. 이름·접수번호 등으로 목록을 검색할 수 있습니다.
3. **접수 등록** 또는 접수번호를 누르면 전용 상세 화면이 열립니다. 담당 동·신청자·주소·예정일·품목을 입력하고 저장합니다. **목록으로 · 초안 보관**으로 돌아가면 날짜·동·검색조건과 목록 위치를 유지합니다. 초안은 원래 동에서 다시 열 수 있으며 계정이 바뀌면 초기화됩니다. 브라우저를 닫은 뒤의 보관 수단은 아닙니다.
4. 수거 위치를 확인합니다. **주소로 위치 찾기**는 PC에 설치된 주소 자료를 사용합니다. 자료가 없으면 위치를 직접 입력하거나 전체 업무 담당자에게 확인을 요청합니다. 위치가 없는 접수는 노선에 넣을 수 없습니다.
5. 팀을 선택해 **노선 계산**으로 미리 보고, **배정 확정**에서 반영합니다. 날짜·동·팀이 바뀌면 다시 계산합니다. 휴대폰 목록 전송은 전체 업무 담당자가 기존 전송 화면에서 처리합니다.

## 충돌과 자료 범위

다른 동의 접수가 섞인 기존 팀 배정은 이 화면에서 통째로 교체하지 않습니다. 전체 업무 담당자에게 조정을 요청하세요. 다른 사람이 접수나 배정을 바꾼 경우 최신 내용을 확인한 뒤 다시 작업합니다.

**집계 CSV**에는 현재 허용 범위의 동별 건수만 담으며 주민명·전화번호·주소는 포함하지 않습니다. 동 담당자에게는 전역 보고서·수납·출력·파일 전송 메뉴가 제공되지 않습니다. 담당 범위 밖의 상세 조회나 변경 요청도 서버가 거부합니다.

## 업데이트 확인

0.14.0의 DB 구조 버전은 **8**입니다. 업데이트 시 기존 계정·접수 등을 보존하며 구조 변경 전 암호화 사본을 만듭니다. 이전 프로그램으로 새 DB를 직접 열지 마세요. 가상 동·가상 주민 자료로 계정별 범위와 첫 로그인 흐름을 확인한 뒤 사용합니다.
