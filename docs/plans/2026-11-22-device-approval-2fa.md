# 새 수거폰 승인 2단계 인증 구현 계획

새 수거폰의 사용을 승인할 때 현재 관리자 계정의 비밀번호와 인증 앱 번호를 확인한다. 일반 로그인과 기존에 승인된 수거폰 사용은 종전 흐름을 유지한다.

1. `pc/dgpc/device_approval.py`와 DB 이전 단계에서 관리자별 인증 앱 등록, 교체, 복구코드, 연속 실패 제한과 번호 재사용 차단을 구현한다. `tests/test_device_approval.py`에서 실제 임시 암호화 DB로 확인한다.
2. `pc/dgpc/server.py` 및 `pc/pc_tool.py`에서 관리자가 승인하는 동작을 공통 경로로 연결한다. 중계가 기기 서명을 확인한 뒤에도 새 수거폰은 승인 대기로 남는다. HTTP 시험에서 권한, 기존 기기, 누락된 인증, 정상 승인과 재시도를 확인한다.
3. `web/screens/register.js`에서 공개 기기 코드만 담은 등록 파일을 내보낸다. `pc/ui/screens/settings.js`에서 파일을 읽어 두 화면의 지문을 대조하고 관리자 승인을 받는다. 파일 오류·취소와 기존 QR 경로를 브라우저에서 시험한다.
4. PC와 모바일 버전을 맞추고 사용 설명과 경로 표를 갱신한다. 기존 기기 등록·배정·전송 시험은 실제 관리자 승인 단계를 거쳐 실행한다. 운영 기기와 운영 DB는 시험에서 제외한다.
