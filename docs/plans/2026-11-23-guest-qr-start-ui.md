# 휴대폰 배차 QR 시작 화면

홈의 **배차 QR로 업무 시작**을 한 번 누르면 열쇠 QR 카메라를 연다. 받은 목록 열기와 이전 현장 기록 이어보기는 읽던 자료를 바로 보여 준다.

1. `tests/test_guest_list_workflow.py`에서 버튼 한 번으로 카메라가 열리는지, 열쇠 인식 뒤 두 번째 단계가 표시되는지 확인한다. 촬영을 취소하거나 저장된 배차를 다시 열 때 카메라가 켜지지 않는지도 확인한다.
2. `web/screens/home.js`와 `web/screens/guest-list.js`에서 사용자가 누른 첫 배차 시작 의도를 한 번만 소비한다. 저장된 목록·미전달 기록을 다시 확인한 뒤 화면이 표시되면 카메라를 연다.
3. 촬영 화면에 ‘1 열쇠 QR → 2 목록 QR’를 함께 표시한다. 열쇠 인식 뒤 현재 단계를 바꾸고 PC에서 누를 버튼을 안내한다. 카메라 권한 거부 시 그 자리에서 다시 열 수 있게 한다.
4. `web/style.css`에서 작은 휴대폰의 촬영 영역과 동작 버튼을 맞춘다. 가상 카메라로 실제 PC QR, 권한 오류 복구, 앱 잠금, 오프라인 목록 재열람 및 결과 전달을 시험한다.
