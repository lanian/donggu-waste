# USB로 수거폰 등록

업무 PC에서 데이터용 USB 케이블과 휴대폰의 USB 테더링으로 연결한 수거폰을 등록한다. 새 폰이 PC의 QR을 읽고 휴대폰에서 등록 정보를 보내면 관리자가 PC에 수거폰의 6자리 번호를 입력한다. 최종 승인은 기존 관리자 비밀번호와 관리자 인증 앱을 사용한다.

1. `pc/usb_pairing.py`에서 Windows가 인식한 휴대폰 USB 네트워크의 사설 IPv4 한 곳만 선택한다. 등록을 시작할 때 해당 주소의 임의 포트에서 5분 동안 한 건의 암호문을 받는다. 취소, 만료, 등록번호 확인 시 수신을 종료한다.
2. `pc/device_pairing.py`와 `pc/dgpc/server.py`에서 관리자 세션에 귀속된 USB 등록 QR을 발급한다. 기존 수거폰 서명 검증, 등록번호 시도 제한, 관리자 승인 및 수거팀 연결을 재사용한다.
3. `web/pairing.js`와 `web/screens/register.js`에서 수거폰 자체 키로 서명한 등록 자료를 암호화한다. 사용자가 누른 링크로 USB 수신 화면을 열어 암호문을 전달하고 수거 앱에서 6자리를 확인한다. PC 관리 API와 등록 비밀은 USB 수신 화면에 제공하지 않는다.
4. `pc/ui/screens/settings.js`에서 등록 시작, 연결 안내, 실패 후 재시도, 만료를 표시한다. USB 연결과 외부 중계 설정은 독립적으로 동작한다.
5. 임시 DB, 루프백 수신기와 독립 브라우저 세션으로 등록번호 확인과 관리자 최종 승인을 시험한다. Windows의 실제 어댑터 감지와 휴대폰 브라우저에서의 USB 연결은 실물 검증 항목이다.
