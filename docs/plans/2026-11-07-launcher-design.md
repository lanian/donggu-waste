# Server Launcher Design Implementation Plan

**Goal:** 서버 실행 앱을 화이트·딥네이비의 간결한 Windows 업무 도구로 개선하고 실제 배포 실행 파일까지 제공한다.

**Architecture:** 기존 Tk/ttk와 DesktopView 표시 계층을 유지한다. 작은 브랜드 헤더, 둥근 상태 카드, 텍스트 상태 배지, 네이비 주 버튼, 분리된 종료 버튼으로 계층을 만든다. 서버·DB·인증·소유권·재연결·작업 큐는 변경하지 않는다.

**Tech Stack:** Python Tk/ttk, 로컬 벡터 도형, 기존 맑은 고딕, PyInstaller. 새 런타임 의존성 없음.

## 설계 기준

이전 사용자 선택인 화이트·딥네이비 업무형과 현재의 간결한 배치를 확장한다. 색만 바꾸는 안, 시각 계층을 개선하는 안, UI 프레임워크를 교체하는 안 중 두 번째를 적용한다. Microsoft Fluent 2의 [명확한 타이포그래피](https://fluent2.microsoft.design/typography), [절제된 둥근 모서리](https://fluent2.microsoft.design/shapes), [표면 계층](https://fluent2.microsoft.design/elevation)을 참고한다. 서버 관리에 필요한 상태·다음 동작을 우선하고 측정되지 않은 백분율은 만들지 않는다.

## 구현·검증

1. `pc/desktop_view.py`: 표시 전용 둥근 카드, 브랜드 마크, 상태별 배지·아이콘·강조색, 버튼/텍스트/간격 정리. 기존 public 위젯·콜백·오류/경로 전문·키보드 포커스 유지.
2. `pc/desktop.py`: 기본 창 크기만 조정. 최소 크기 560×400 유지. 실행 제어 코드는 수정하지 않는다.
3. `tools/preview_desktop.py`: 실제 서버·DB 없는 가상 상태 미리보기. 운영 정보·키·네트워크 접근 없음.
4. 기존 `tests/test_desktop_ui.py`로 100/150/200%와 560×400~720×560 경계·Enter·초안·재연결·종료 소유권 검증. 새 시각 요소는 가상 상태별 수동 검토하며 단순 색상 복제 시험은 추가하지 않는다.
5. 실제 자식 프로세스·정상 종료 회귀, 버전·생성물·구문 검증 뒤 전체 실행 앱을 새 버전 폴더에 빌드한다. 실제 EXE를 임시 자료에서 확인하고 바로가기만 새 버전으로 연결한다. 기존 사용자 서버·DB는 건드리지 않는다.

## 검토 제한

초기 가상 Tk 창은 Computer Use 목록에서 확인했지만 화면 캡처가 timeout, 재선택 후 전면 표시가 실패했다. 해당 창의 UI 입력을 중단했다. 기존 Tk 실제 위젯 경계/키보드 시험과 동작 검증은 별도로 수행한다.

## 결과

- 표시 계층과 기본 창 크기를 개선했다. 준비/입력/실행/기존 서버/연결 끊김/종료/오류 배지, 벡터 상태 마크, 둥근 카드와 주 버튼을 적용했다. 서버 제어·DB·비밀번호·소유권 코드는 변경하지 않았다.
- 실제 Tk UI 46개 통과: 100/150/200% 및 560×400~720×560, 고정 동작/오류 복구, 경로 전문 복사, Enter, 포커스 복귀, 연결 상실·재연결·종료 의도. 200% 최소 창의 오류 상태 정보 영역은 44px로 최소 40px 기준을 충족했다.
- 기존 서버 확인 fixture는 초기 자동 열기 전체 기록을 보존하고 수동 재연결 직전 정확히 1회임을 검증하도록 수정했다. 20ms 가상 확인과 화면 그리기 순서에 의존한 `opened.clear()`를 제거했다. 실패 추가 열기 0회/성공 1회 및 기존 호출·소유권 assertions를 유지했고 교착 가드는 5초로 조정했다. 실제 서버 확인 주기는 변경하지 않았다.
- 실행·소유권 회귀 49개와 진행 작업 완료를 기다리는 실제 종료 통합 흐름 통과. 0.13.7 EXE의 headless child에서 Python 없는 PATH·공백 경로·공개 자산·SQLCipher·ORTools·정상 종료 확인. 실제 사용자 DB·현재 서버·계정에는 적용하지 않았다.
- 가상 python/pythonw 창은 목록에서 확인했으나 Computer Use 캡처 timeout으로 렌더링 픽셀 검증은 완료하지 못했다. 재선택/전면 표시 복구도 실패해 UI 입력을 중단했고 본 작업의 가상 미리보기만 종료했다. Tk 위젯·동작 시험 결과와 시각 캡처 결과를 구분한다.
- 버전/생성물/구문/diff 검사 통과. ZIP `dist/desktop/v0.13.7/Donggu-PC-windows-x64.zip`, 66,469,534 bytes, SHA256 `e6f1c4cacf6baf98279e044c0905e643cd5b043a1c5f117b9f13c04eb97c7d78`. 이전 배포본은 보존한다. 커밋·원격 배포는 하지 않았다.
