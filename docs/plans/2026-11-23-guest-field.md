# 수거팀 현장 업무와 선택형 기기 연결

수거팀은 PIN을 정한 뒤 업무 PC의 팀 배차 QR을 읽어 일한다. 기기 등록은 설정에서 선택한다. 기존에 등록한 휴대폰은 이미 받은 목록, 사진, 전송 이력을 계속 사용한다.

1. 첫 사용과 목록 홈의 주 동작을 배차 받기로 바꾼다. 실제 화면 시험에서 기본 동작과 설정의 선택형 등록을 각각 확인한다.
2. PC가 팀·날짜·방문·품목 범위와 발급 당시 상태가 묶인 현장 업무 QR을 발급한다. 기존 조회용 QR은 계속 조회 전용으로 읽는다.
3. 휴대폰은 현장 접수, 품목별 수량과 추가 품목, 수거 결과, 회차별 하차를 기록한다. 오프라인에서 암호화해 보관하고 PC에 전달할 암호화 파일을 만든다.
4. PC는 파일을 읽어 접수·수거·하차 내역을 먼저 보여 준다. 담당자가 확인하면 발급 범위와 현재 배차를 다시 대조하여 반영한다. 데이터 변경, 동일 기록 재전송, 승인 취소를 시험한다.
5. 실제 PC 발급 QR을 브라우저 카메라로 읽고 결과 파일을 PC 화면에 다시 가져오는 가상 업무를 검증한다.
