# 미등록 휴대폰 배차 목록 조회 구현 계획

업무 PC에서 선택한 팀과 수거일의 방문 순서, 배출 주소, 품목과 남은 수량을 개인 휴대폰으로 가져온다. 수거 결과는 담당자가 PC에서 입력한다.

1. PC는 현재 배정에서 휴대폰에 보낼 방문만 추린다. 조회용 데이터는 허용한 필드만 새로 만들고 발급 사실을 기록한다. 발급마다 새 암호 키를 사용한다. PC 화면에서 열쇠 QR을 먼저, 암호화된 목록 QR을 다음에 표시한다. 두 QR을 함께 복제하면 목록을 열 수 있으므로 화면을 수거원에게 직접 보여 준다.
2. 휴대폰은 PIN을 설정한 뒤 PC 화면을 읽는다. 두 단계가 같은 발급 건인지와 전체 조각을 확인하고, 복호화가 끝난 목록만 별도 PIN 보호 저장소에 쓴다. 다른 팀이나 날짜로 바꿀 때 확인을 받는다. 창을 닫거나 저장에 실패해도 기존 업무 기록을 유지한다.
3. 실제 PC 발급과 브라우저의 QR 인식기를 가상 배차로 연결한다. 오프라인 재열람, 수거일 경과, 조회 자료 삭제, 팀 배차의 수신 확인 및 현장 기록과의 분리를 검증한다. 등록된 휴대폰용 QR과 기존 홈 화면도 회귀 시험한다.
